## How the AI Output Was Checked

The pytest suite, containing 99 tests, was run after every change. Sample outputs in `data/` were regenerated using the project scripts. The two worked examples in the assignment statement, Wednesday Addams and the ML Engineer sequence, were used as reference cases, and the pipeline reproduces both.

All references in `literature_review.md` were checked against their publishers or bibliographic indexes. The verified references include Mohri (1997), *Computational Linguistics* 23(2), pp. 269–311; Dejanović et al. (2017), *Knowledge-Based Systems* 115; Beesley and Karttunen (2003), CSLI Publications; Chomsky (1956), *IRE Transactions on Information Theory* 2(3), pp. 113–124; Fowler (2010), Addison-Wesley; Hopcroft, Motwani, and Ullman (2006), 3rd edition, Addison-Wesley; Sipser (2012), 3rd edition, Cengage; and Karttunen et al. (1996), *Natural Language Engineering* 2(4), pp. 305–328. The last reference was confirmed through Cambridge Core (DOI: 10.1017/S1351324997001563). Since some secondary sources report an incorrect page range for this article, the publisher's page was used.

The poster guide from the CWU library was reviewed using a tool that summarizes web pages. Its layout figures should therefore be checked against the original page.

## Errors Found During the Work

Several errors in the AI's initial versions were identified through testing or manual review. Each was corrected and is worth understanding.

The education regex failed to match `B.Sc.` because of a trailing `\b` after a period. It also captured the following line as part of the education field because it used `\s`. The ML Engineer and Data Engineer orders initially accepted only the literal word `SQL`, rather than database technologies more generally, contradicting the assignment's own example. The first textX object processor had an incorrect number of parameters. The initial citation for textX identified the wrong publication venue. Additionally, some documents described two sample résumés as matching two profiles before the actual data supported that claim.

All these issues were corrected, and the relevant changes are documented in the corresponding project files.
